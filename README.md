Sou desenvolvedor Full Stack em formação, com foco no desenvolvimento de aplicações web, especialmente no backend com PHP e Laravel.

## 💻 Projetos em Desenvolvimento

### 🏥 Sensus — Sistema de Gestão de Consultas

Sistema web para gestão de consultas e agendamentos de uma clínica.

**Tecnologias:** Laravel 12, PHP, MySQL, Blade e Tailwind CSS.

Funcionalidades:
- Autenticação e gestão de perfis.
- Perfis de administrador, médico e paciente.
- Gestão de agendamentos.
- Gestão de médicos e especialidades.
- Controlo de acesso e permissões.
- Histórico de consultas.
- Gestão e acompanhamento dos estados dos agendamentos.

### 📝 Blog — Sistema de Publicação de Conteúdos

Aplicação web para publicação e gestão de artigos.

**Tecnologias:** Laravel, PHP, MySQL e API REST.

Funcionalidades:
- Gestão de publicações.
- Gestão de categorias.
- Relacionamentos entre utilizadores, categorias e publicações.
- Upload de imagens.
- Autenticação e controlo de propriedade dos conteúdos.
- Desenvolvimento de endpoints e respostas JSON.

### 🏫 Sistema de Gestão Escolar

Projeto de desenvolvimento de um sistema para gestão de processos escolares.

**Tecnologias:** PHP, MySQL, HTML, CSS e JavaScript (projetos iniciais), com evolução da aprendizagem para Laravel.

Objetivo: digitalizar processos administrativos e académicos, facilitando a gestão de alunos, professores e outros intervenientes.
